Link Lock · Encrypt a URL

zero-knowledge

Encrypts a URL entirely inside the generated link. Nothing is stored on any server, no cookies, no signups. Encryption uses AES-256-GCM with PBKDF2 key derivation (100,000 iterations, SHA-256). To unlock an encrypted URL, the visitor just needs the password — everything else is in the link itself.

Link Lock · Advanced Options 0 active
A random salt is generated per-link and embedded in the URL. It strengthens protection against rainbow-table attacks, at the cost of a slightly longer link.
Password is never sent anywhere.

// Client-side Link Lock encryption — no network request const ITERATIONS = 100000; const SALT_LEN = 16; const IV_LEN = 12; async function deriveKey(password, salt) { const enc = new TextEncoder(); const km = await crypto.subtle.importKey( 'raw', enc.encode(password), 'PBKDF2', false, ['deriveKey']); return crypto.subtle.deriveKey( { name: 'PBKDF2', salt, iterations: ITERATIONS, hash: 'SHA-256' }, km, { name: 'AES-GCM', length: 256 }, false, ['encrypt','decrypt']); } async function encrypt(plaintext, password) { const salt = crypto.getRandomValues(new Uint8Array(SALT_LEN)); const iv = crypto.getRandomValues(new Uint8Array(IV_LEN)); const key = await deriveKey(password, salt); const ct = new Uint8Array(await crypto.subtle.encrypt( { name: 'AES-GCM', iv }, key, new TextEncoder().encode(plaintext))); const all = new Uint8Array(SALT_LEN + IV_LEN + ct.length); all.set(salt, 0); all.set(iv, SALT_LEN); all.set(ct, SALT_LEN + IV_LEN); return 'v1.' + btoa(String.fromCharCode(...all)) .replace(/\+/g,'-').replace(/\//g,'_').replace(/=+$/,''); } // Append to current URL: location.href + '#' + await encrypt(url, pwd)

Endpoints

POST /api/create

Create a new short link. Body: url plus optional alias, password, expires_at, max_clicks, UTM fields.

TinySRC /v1/create

Body: url, auth_required (0/1), password, expiration_time. Returns url, is_free, stat_url, stat_password.

No endpoint. Encryption and decryption run entirely in the browser with the Web Crypto API. The encrypted payload is embedded in the URL fragment.

FAQ

Is this URL shortener free to use?
Yes. Every feature is free, with no account and no monthly link cap.
Does the URL shortener API require an API key?
No. Send a POST request to https://zip1.io/api/create with your URL and you get a short link back. https://api.tinysrc.me/v1/create also works without any key. Link creation is limited to 10 a minute per IP.
How do I use the TinyURL API section?
Open the TinyURL API tab. Paste your TinyURL v2 token (get one from tinyurl.com/app/settings/api), then use the Shorten a Link panel to create a branded short URL on tinyurl.com or a custom domain. The QR Code panel generates a PNG QR code for any destination URL.
What does "auto-generate alias" mean?
When enabled (default), if you leave the alias blank, the tool generates a random 6–8 character alias for you before calling the API. Aliases must be at least 5 characters long, matching TinyURL's rules.
Can I use a custom domain with TinyURL?
Yes. Enter your branded domain (e.g. go.mybrand.com) in the Domain field of the Shorten a Link panel. You must have already configured the domain in your TinyURL dashboard.
How does Link Lock encryption work?
Link Lock encrypts a URL inside the generated link itself using AES-256-GCM. The key is derived from the password with PBKDF2-SHA256 at 100,000 iterations. The salt and initialization vector are stored alongside the ciphertext. Nothing is sent to any server — everything happens locally with the Web Crypto API.
Is the password stored anywhere with Link Lock?
No. The password is only used locally to derive the encryption key. It is never sent anywhere and is not stored in the encrypted URL. If you forget the password, the encrypted URL cannot be recovered — this is by design.
Can I cap the number of clicks on a link?
Yes. Set a click limit under Advanced Options on the Shorten tab. After that many clicks, the link stops redirecting and shows an expired-link page.
Can I add UTM tags to a short link?
Yes. Open Advanced Options on the Shorten tab and fill in source, medium, campaign, term and content. They are added to the destination before saving so every click carries the tags.
Is there an MCP server for AI agents?
Yes. A built-in MCP server lets Claude or any agent create short URLs on demand using the same no-auth REST API.
